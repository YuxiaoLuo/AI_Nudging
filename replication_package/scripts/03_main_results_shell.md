# 03 Main Results Shell

## Responsibility
Generate the main confirmatory evidence for the manuscript.

## Inputs
- construct-scored confirmatory dataset from `02_constructs`
- fixed condition coding
- stable confirmatory covariate set

## Main steps
1. Generate Table 1 descriptive statistics and correlations.
2. Estimate headline treatment effects on:
   - purchase likelihood
   - perceived decision quality
3. Report conversational-versus-UI and conversational-versus-control contrasts.
4. Estimate the planned mechanism-path model or the theory-consistent staged alternative if needed.
5. Produce the outputs needed for:
   - Table 2 headline treatment effects
   - Table 3 mechanism-path results
6. Preserve confidence intervals and interpretable effect-size outputs wherever supported.

## Outputs
- Table 1 inputs
- Table 2 inputs
- Table 3 inputs
- main model estimates

## Guardrails
- Keep the conversational-versus-UI comparison central.
- Do not mix secondary outcomes or robustness variants into the main confirmatory output objects.
