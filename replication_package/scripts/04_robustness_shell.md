# 04 Robustness Shell

## Responsibility
Run bounded supporting analyses after the confirmatory results are fixed.

## Inputs
- main confirmatory outputs from `03_main_results`
- screened dataset and construct dataset

## Main steps
1. Summarize manipulation checks by condition.
2. Generate the secondary outcome results for:
   - trust
   - satisfaction
3. Run any bounded screening-variant sensitivity checks.
4. Run any narrow estimation checks that defend rather than redefine the main results.
5. Populate the supporting displays planned for:
   - Table 4
   - `appendix_d_supplemental_robustness.md`

## Outputs
- secondary-outcome table inputs
- robustness table inputs
- manipulation-check summaries

## Guardrails
- Do not create an exploratory appendix that competes with the confirmatory narrative.
- Keep every check explicitly labeled as secondary, robustness, or diagnostic.
